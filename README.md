# Encryption Backend (C++ + pybind11)

**Version:** 2.0.0 (Refactored)  
**Python Version Required:** 3.14

This project provides a high-performance C++ backend for password hashing and data encryption, exposed to Python via pybind11. It includes a modern GUI for secure file encryption.

## Features

- **Password Hashing:** Custom iterative algorithm with configurable cost factor
- **Salt Generation:** Cryptographically secure random salt generation
- **Password Validation:** Strength checking against security policies
- **Data Encryption:** XOR-based encryption with bit rotation
- **Modern GUI:** Beautiful glassmorphism interface for file encryption
- **High Performance:** C++ implementation for speed-critical operations

## API Usage

```python
import encryption_backend as backend

# Hash a password
password = "Secret123!@#"
hashed = backend.hash_password(password, cost=12)

# Check password strength
is_strong = backend.check_password_strength(password)

# Encrypt data
data = b"Secret information"
key = hashed.encode('utf-8')
encrypted = backend.encrypt_data(data, key, rounds=3)

# Decrypt data
decrypted = backend.decrypt_data(encrypted, key, rounds=3)
```

See `docs/API_REFERENCE.md` for complete documentation.

## Manual Build (Advanced)

If you need to build manually or for a different Python version:


## Module Functions

### Password Hashing
- `generate_salt(bytes=16) -> str` - Generate random salt
- `hash_password(password, cost=2, salt=None) -> str` - Hash password
- `check_password_strength(password) -> bool` - Validate password

### Data Encryption
- `encrypt_data(data, key, rounds=1) -> bytes` - Encrypt data
- `decrypt_data(encrypted_data, key, rounds=1) -> bytes` - Decrypt data

## Extending

1. Add new functions to appropriate `.h` and `.cpp` files
2. Expose in `binding.cpp` using pybind11
3. Rebuild with `.\build.ps1 -Clean`
4. Update `API_REFERENCE.md` with new functions

## Troubleshooting

### "ImportError: DLL load failed"
- Ensure you're using Python 3.14 (64-bit)
- Rebuild the project: `.\build.ps1 -Clean`
- Check Python path in CMakeLists.txt

### "Python3 not found" during build
- Update the `Python3_ROOT_DIR` in `cpp/CMakeLists.txt`
- Ensure Python 3.14 is installed

### GUI doesn't start
- Run `.\run_test.ps1` to verify the module works
- Check that tkinter is available: `python -m tkinter`
